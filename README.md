### 🌿 Plant Disease Classification (CNN & ResNet50)

Deep learning model for classifying plant leaf diseases using the PlantVillage dataset.

* Custom CNN baseline and ResNet50 transfer learning
* Achieved ~99% accuracy with ResNet50
* Implemented using PyTorch

### 🧠 Brain Tumor Segmentation (U-Net)

Medical image segmentation model for detecting brain tumors in MRI scans.

* U-Net architecture (TensorFlow/Keras)
* Evaluated using Dice coefficient and IoU
* Mean IoU: 0.71

📂 [View Project](./projects/computer-vision/brain-tumor-segmentation-unet)

### 🐛 Rice Pest Instance Segmentation (Mask R-CNN)

Instance segmentation model for detecting agricultural pests in rice crops.

* Mask R-CNN with Detectron2
